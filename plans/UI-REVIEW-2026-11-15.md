## 一、仍然没做好的（按严重度）

### A1 NP 展开层进度/时间恒显 0:00/0:00（P1，复现稳定）
- `restoreLast()`（app.js:2430）只画了迷你条（`#curTime`/`#allTime`/`#seekFill`/`#seekDot`），
  **不画 NP 层**；`paintSeek()`（app.js:2473）才同步 `#np*`，但它直读 `<audio>` 元素，
  而恢复态下 audio 还没加载（`currentTime=0`、`duration=null`）。
- 运行时实测：迷你条显示 `0:24 / 3:28`，NP 展开层显示 `0:00 / 0:00`，两处同时存在、数据不同源。
- 修法：`restoreLast()` 里对 `#npCurTime/#npAllTime/#npSeekFill/#npSeekDot` 做同一份绘制
  （复用 pos/dur 局部变量即可，不必等 audio 事件）。

### A2 歌词失败占位的「重试」按钮文字竖排（P1，已实锤）
- `.np-lyric` 带 `white-space:pre-wrap`（style.css:2148），`.np-lyric > .muted`
  （style.css:2170）与按钮**没重置 white-space** → CJK 可任意断字、flex 最小宽=1 字，
  按钮被压成 45px，「重试」竖排成「重/试」。运行时实测 `offsetWidth=45、whiteSpace=pre-wrap`。
- 同一行里两行正文 + 一个双行按钮，是当前全屏层最丑的一幕。
- 修法：`.np-lyric .muted, .np-lyric .muted * { white-space: nowrap; }`，行内容器允许 wrap。

### A3 歌词失败占位锚在左上，四周巨大黑洞（P2，设计）
- `.np-lyric > .muted` 是 inline-flex，无垂直居中 → 错误信息孤零零钉在歌词区顶部，
  下方 700px 全空（截图实锤）。观感像「页面没渲染出来」，不像「这首歌没词」。
- 修法：给该占位 `display:flex; margin:auto; align-items:center; gap:12px`
  （与 `.np-main .empty{margin:auto}` 同一范式），或配一张小插画。

### A4 我的统计两张图在零数据时渲染成「两条虚线」（P2，设计/空态缺位）
- 「近 30 天」30 根柱 `height:3%`、「时段分布」24 根同样 3%（内联样式实测 max=3%），
  1.6px 高的 accent slivers，0.5 透明度 → 远看就是两条红色虚线 + 大片黑底，**没有任何空态文案**。
- `.stats-empty`（style.css:1337）已定义但从未接入这两个图。
- 附带：「近 7 天收听 3」vs「累计时长 0 h / 累计天数 0」口径自相矛盾（次数有、时长为 0），
  暴露给用户像 bug。
- 修法：检测 all-zero 时整块换渲染 `.stats-empty` 文案（如「先听几首歌，这里就有曲线了」），
  顺带核对 stats 累计口径。

### A5 浅色主题对比度系统性不达 AA（P2，12/11 只修了 muted）

## 二、美化不足 / 观感问题（审美层，非阻塞）

### B1 浅色首页 hero 主视觉近乎不可见
`art/home_hero_light.webp` 实为近白底上 ≈5% 对比度的蔷薇线稿（已直接查看原图确认），
浅色主题首页右半屏等于被掏空；暗色版同构图有明确紫色主视觉。`taste_banner_light.webp` 稍好同病。
浅色用户在这个位置丢了品牌瞬间。修法：浅色版加深 8–12% 对比度重导出，或加一层淡 accent 渐变罩。

### B2 风格电台页的歌曲行是纯文字堆叠
每风格卡内 6 首歌 = 歌名/歌手两行 plain text，无封面、无悬停播放键、无行分隔，
与全站 shelf 语言（封面卡 + 悬停操作 + 来源/音质徽标）完全割裂，观感像「文本 dump」。
至少应补：行首 28–32px 圆角封面 + 悬停播放/加入队列图标组，与搜索结果行对齐。

### B3 NP 层「无词/失败/加载中」三态都挤在左上三分之一
Dock 完整、歌词区 70% 留空时，整页气质从「全屏沉浸」塌成「未完成页」。见 A2/A3 的居中化修复可一并解决。
（无词态建议：小型插画 + 「这首歌还没有歌词」+ 重试/去搜索同词入口）

### B4 常听歌手榜用 0 次听手填满 6 席
口味画像页「常听歌手 06」03–06（林俊杰 0 / Mrs. GREEN APPLE 0 / 买辣椒也用券 0 / 叶子舒 0）
全是 0 次 + 空灰色进度条，「常听」语义被注水。建议只列 >0，其余席位渲染「先听几首」占位，
或按真实数据决定席位数。

### B5 小件堆料
- 标题栏窗口按钮用 unicode 字形 `─ □ ✕`（index.html:74-76），与全站 SVG 图标体系割裂，
  且不同字体渲染高度不一。
- 「LOSSLESS PLAYER」出现两处（标题栏 + 侧栏 brand），浅色下近乎隐形，且没 `aria-hidden`（读屏器会念）。
- 我的统计数字用带斜杠零的 mono（`0h`、`0` 长得像被划掉）；换普通等宽或关掉 slash-zero。
- 为你推荐卡封面加载失败时 `onerror=this.remove()`，card-art 死黑块无兜底（无首字/图标），
  与空态插画体系脱节。
- 风格电台页 kicker 仍写 `ALL STYLES`，与更名后的「风格电台」口径不一致。

### B6 窄宽下的硬截断（未在 390px 验证）
≈536px 宽时结果表标题列被压到硬截断（「江南-《你很》电…」），来源 chip + 音质按钮固定占 ~150px。
390px 真机上只会更糟；建议 ≤560px 时表格切「双行行卡」（第一行 封面+歌名截断两行、第二行 歌手·来源·时长）。
（本轮审查窗口被限宽在 536px，390px 真机排版未验证，此条待手机端复核。）
