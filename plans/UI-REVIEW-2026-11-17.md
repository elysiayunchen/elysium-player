> 起因：用户反馈「UI 有时候交互还是会有粗糙感」。11-15 批次（A1-B6）落地后，
> 本轮用隔离实例（`main.py --serve` + 独立 `ELYSIUM_HOME`，端口 2820，
> `web/` 以 junction 挂进资源根）+ 浏览器实测逐页走查：首页 / 搜索 / 播放 /
> NP 层 / 队列抽屉 / 换源 / 收藏 / K 歌层（ready 与无麦演唱态）/ 浅色主题。
> 与 11-15 审查互补：A1-A7、B1-B6 的修复全部在场且仍有效（NP 进度同步、
> 歌词错误占位居中、浅色 AA、无麦文案口语化等逐项复核过）。

## 一、发现并修复（F1-F3）

### F1 错误 toast 直出机读串（P1，11-12 已知遗留项，本轮收口）
- 复现：贴坏歌单链接 → toast「歌单解析失败：获取歌单失败，接口异常」——
  双「失败」叠词 + 后端黑话；`HTTP 502` / `Failed to fetch` / `NotAllowedError`
  等原始串可经 `e.message` 直达 UI（全站 ~40 处 `toast(...e.message...)`）。
- 修法：`humanizeErr()`（app.js）挂在 `toast(kind='err')` 一层——**只认熟面孔**
  （HTTP 码 / 英文 Error 名 / 「接口异常」「签名过期」等机读模式），认不出的
  中文原文原样保留，不改坏后端精心写的文案；带「前缀：」的保留前缀，
  失败的是哪一步仍在。规则表 11 例单测全过（含 4 例「不该改写」的反例）。
- 实测：坏歌单链接 → 「歌单解析失败 · 音源服务这会儿不稳定 · 稍后再试」。

### F2 结果行时长列恒 0:00（P1，观感像坏掉）
- 复现：搜索 16 行时长列全 0:00，而尺寸/音质探测都完成；屋顶正在播
  （footer 明明 5:19），行内仍 0:00。根因两层：
  ① wyy 搜索上游不回时长（kuwo 回），探测只拉 256B 头也算不出；
  ② 播放侧明明拿到了真时长（audio.duration）却从不回填行。
- 修法（三条，全走「只认实测」口径）：
  1. **probe 白捡真时长**：FLAC 探测的 `_flac_hires`（STREAMINFO）本就带
     duration——`paintProbeCells` 顺手回填 `.tr-dur`，同时登记会话表
     `DUR`（plat:id→秒），重渲染不再丢；
  2. **播放侧回填**：`loadedmetadata` 里 `rememberDur()` 记 DUR + 就地改格子；
  3. **alts 兜底**：行渲染 `knownDur(it) || altDur(it)`（折叠同曲 ±4s 口径）。
  - 顺带：后端 `probe_one` 用 STREAMINFO 时长把 `kbps` 补算出来
    （大小、时长都是实测值）——chip 从「FLAC」升级成「FLAC 705k」，
    上一版 kbps 只有上游给了 duration 才有。
- 实测：「起风了」37 行全带时长 + 实测码率（705k/1765k/2832k…）；
  wyy 源的屋顶播放后行内 0:00 → 5:19。

### F3 歌词「重试」点击零反馈 + 放大层占位失联（P1-P2）
- 复现（上游 502 时）：点「重试」→ 页面纹丝不动像没点过。根因两个：
  ① 失败太快时「正在取歌词…」只闪 <100ms 就被错误占位盖掉，无可见过渡；
  ② **真 bug**：`lrc-retry` 的加载/失败态只写 `#npLyricBody`，若用户在
  歌词放大层（`#lyricBody`）里点的重试，可见容器完全不更新（成功路径
  本来就双容器都画，占位路径漏了）。
- 修法：占位统一 `paintLyricState()` 双容器同画（与成功路径对齐）；
  `_lyricSeq` 令牌防旧失败晚到改写新一轮占位（顺带修掉原有的跨曲竞态）；
  `lyricMinWait(450ms)` 快速失败也要让加载态被看见；`showLyric` 同款延迟，
  层已关时不写占位。
- 实测（getlyric stub 失败注入复现 502 路径，验证后已还原）：点重试
  t+200ms 停在「正在取歌词…」，t+2s 才落错误占位——反馈可见。

## 二、查证后排除（记录防复读）

- **Escape 关不掉音质菜单**：证伪。全局 keydown 本就调 `closeQualityMenu()`
  （app.js:6926 一带），复测一次即关；首次误判是 CUA 按键未送达页面。
- **点击搜索结果行无响应**：证伪。坐标点击即播；Playwright locator 的
  actionability 超时是 IAB 后端怪癖，非应用缺陷。
- **收藏后跳歌**：证伪。上一首当时已播到 3:42/3:58，观察窗口内自然切歌。
- **截图内容重复渲染**：IAB clip 截图合成伪影（DOM 只有 1 份、无 overlay/
  iframe），全屏截图正常。

## 三、本轮未做（超范围 / 待决定）

  播过即回填）——诚实缺口，不猜数。
- 贴坏链接失败后输入框残留 URL、视图标题与输入不一致——可辩护，未动。
- `lyric-full`（放大层）在 UI 已无入口（孤儿 action），showLyric 的双容器
  修复属防御性对齐；放大层要不要复活/删掉待决定。
- wyy 搜索上游偶发返回空（本轮 verify_ui T1 首跑 real=0，复跑 real=37 全绿，
  期间同接口直戳亦复现空）——上游波动，与前端改动无关；T4 拦截降级路径
  同跑全过。
